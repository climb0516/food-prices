# 🥬 菜价物价 · 猪肉 鸡蛋 蔬菜 CPI

> 每天看猪肉、鸡蛋、蔬菜、水果、鱼的批发价涨跌，全国批发价格指数，以及国家统计局每月的 CPI（猪肉、鲜菜、蛋类同比）

**🌐 在线访问：[https://climb0516.github.io/food-prices/](https://climb0516.github.io/food-prices/)**

---

## 功能

- **概览**：猪肉、鸡蛋、大白菜今日批发价，和 7 天前、30 天前比的涨跌，带 30 天走势线；最新 CPI 同比和「菜篮子」指数；这周涨得最多、跌得最多的品种；一句话看 CPI（猪肉、鸡蛋、鲜菜比去年贵了还是便宜了）
- **今日菜价**：32 个常见品种（肉、蛋、菜、果、鱼虾），元 / 斤，和昨天、7 天前、30 天前比；点一行展开走势图（30 天 / 90 天 / 1 年），悬停看每天价格
- **全国行情**：农业农村部农产品批发价格 200 指数、「菜篮子」指数，以及蔬菜、水果、畜产品、水产品、粮食、食用油分类指数；今日全国涨跌榜
- **CPI**：近 24 个月 CPI 总体、猪肉、鲜菜、蛋类同比走势（可切换表格）；当月各品类同比对比
- 搜索（`⌘K` / `Ctrl K`），深浅色切换，手机适配。涨红跌绿，并带 ▲▼ 箭头

## 技术架构

```
GitHub Actions（定时：每天北京时间 09:00 / 手动 dispatch / push 修改 scraper.py 或 workflow）
  ↓ python scraper.py（Python 3.12，只用标准库，无需安装依赖）
  ↓ 4 路并发抓取（ThreadPoolExecutor(4)）
  ↓   ├─ 北京新发地：最近 7 天全部报价 + 历史不足 20 天的品种回补 90 天
  ↓   ├─ 农业农村部：全国批发价格指数（当天 + 前一天）
  ↓   ├─ 农业农村部：每日涨跌幅榜（当天 + 前一天）
  ↓   └─ 国家统计局：月度 CPI 公报（只解析还没有的月份）
  ↓ 与上一份 data.json 合并（失败的来源沿用旧数据，标「旧数据」）
  ↓ 写入 data.json → git commit & push（updated 每次变化，每次都有提交）
       ↓
GitHub Pages（index.html）
  ↓ fetch('data.json', { cache: 'no-cache' })，四个视图 + 右栏挂件
  ↓ 走势图、迷你走势线全部用内联 SVG 绘制
  ↓ 详情抽屉（#/item/<类型>/<id>）/ 列表页（#/list/movers）
```

## 数据来源

| 来源 | 方式 | 每次条数 / 范围 | 备注 |
|------|------|----------------|------|
| 北京新发地批发市场 | 接口（POST `http://www.xinfadi.com.cn/getPriceData.html`，表单参数分页，每页 `limit=1000`，最多翻 10 页） | 每天查最近 7 天全部报价；`BASKET` 里 32 个品种；历史不足 20 天的品种单独按品名回补 90 天（`BACKFILL_DAYS`） | 只取单位为「斤」的报价；回补逐个品种查，间隔 1 秒防限流 |
| [农业农村部全国农产品批发市场价格信息系统](https://pfsc.agri.cn/) · 指数 | 接口（POST `/price_portal/pi-info-day/getIndexByLevel`） | 当前数据 9 个指数（200 指数、「菜篮子」指数及分类指数），每个只给当天值和前一天值 | 历史由爬虫每天累积到 `moa_index_hist` |
| 农业农村部 · 涨跌榜 | 接口（POST `/price_portal/index/growthRanking`） | 当前数据 20 个品种（涨跌幅榜），含今日均价、前一天均价、涨跌幅 | 单位多为「元/公斤」，累积历史时折算成元/斤 |
| [国家统计局](https://www.stats.gov.cn/sj/zxfb/) | 网页解析（最新发布列表页 + 每月居民消费价格公报正文表格） | 首次往前翻 40 页列表、取最近 24 个月（`CPI_MONTHS`）；之后只翻 3 页，解析新出的月份；最多保留 36 个月 | 公报用 4 线程并发解析 |

**配置位置**：
- 地址常量在 `scraper.py` 开头：`XFD`、`MOA`、`STATS`
- 新发地品种清单是 `BASKET`，每项为 `(id, 显示名, 分组, 新发地品名, 规格)`。规格写 `None` 表示该品名所有「斤」报价取平均，写字符串（如 `"瘦"`、`"750g-1000g"`、`""`）则只认这个规格。增删品种直接改这个列表，新加的品种下次运行自动回补 90 天
- CPI 要抓的行在 `CPI_ROWS`（公报表格第一列文字 → 字段 id），加一行映射即可多抓一个品类；前端显示名在 `index.html` 的 `CPI_NAME`

**说明**：
- 单品价格是**北京批发价**，一般比超市、菜市场零售价低三到五成，看涨跌趋势更有参考价值
- 季节性品种（如脐橙）没有报价的日子会空着，页面上显示最后报价日；超过 3 天没新报价时详情里标「N 天没有新报价」

## 数据处理规则

- **请求重试**（`fetch()`）：最多 3 次，遇到 HTTP 429 / 500 / 502 / 503 / 504 或网络错误、超时时等 `3 × 次数` 秒重试（新发地偶尔 503 限流）；其他 HTTP 错误直接抛出。超时 25 秒
- **新发地取价**（`pick()`）：按 `prodName` 等于品名、`unitInfo == "斤"`、规格匹配（`spec` 为 `None` 时不限规格）筛选，丢掉 `avgPrice` 为空或 ≤ 0 的行，同一天多条报价取平均，保留 2 位小数
- **新发地当日明细**（`pick_meta()`）：取最近一个报价日，多规格时取最低的 `lowPrice`、最高的 `highPrice`；产地 `place` 逐字去重合并（去掉 `\ / 、 , ，`）。本次没抓到的品种沿用上次的 `xinfadi_meta`
- **回补判定**（`xinfadi()`）：历史少于 20 天的品种查最近 90 天；所有品种价格只保留最近 400 天（`KEEP_DAYS`）
- **全国指数历史**（`main()`）：接口只给当天和前一天，每次把当天值写入 `moa_index_hist[指数名][日期]`，前一天值用 `setdefault` 补到前一天日期（不覆盖已有值）；同样保留 400 天
- **涨跌榜历史**：单位为「元/公斤」时乘 0.5 折算成元/斤，写入 `rank_hist`，前一天均价同样补到前一天；保留 400 天
- **CPI 公报识别**（`cpi_links()`）：列表页链接标题匹配正则 `(20\d\d)年(\d{1,2})月份居民消费价格`，生成 `YYYY-MM → 公报地址`
- **CPI 表格解析**（`cpi_month()`）：逐行 `<tr>` 取单元格并去掉空白，第一列命中 `CPI_ROWS`（如「居民消费价格」→ `cpi`、「其中：猪肉」/「猪肉」→ `pork`、「鲜菜」→ `veg`、「其中：不包括食品和能源」→ `core`）时，第 2 / 3 列分别作为环比 `mom` / 同比 `yoy`；同一 id 只取第一次出现；没解析到总体 `cpi` 视为失败
- **CPI 增量**（`cpi()`）：已有月份数 ≥ 22（`CPI_MONTHS - 2`）时只翻 3 页列表，否则翻 40 页；只解析最近 24 个链接里还没有的月份；结果按月份排序保留最后 36 个月
- **失败兜底**（`run()` + `main()`）：每个来源单独 try，失败时沿用上一份 data.json 里的数据，`sources.<来源>` 记录 `ok` / `stale` / `error`（错误信息截断到 200 字）
- **前端涨跌计算**（`index.html` 的 `stat()`）：取最新报价，与「不晚于最新报价日往前 1 / 7 / 30 天的最近一个报价」比，得出较昨日、周、月涨跌；90 天内最低 / 最高 / 均价；「这周涨得最多」按 7 天涨跌幅排序取前 5 / 后 5

## 数据结构

`data.json` 顶层字段：

```
{
  "updated": "2026-10-22T12:48:13+08:00",   // 本次运行时间（北京时间），每次都变
  "today": "2026-10-22",
  "sources": {                              // xinfadi / index / rank / cpi 四个来源的状态
    "xinfadi": { "ok": true, "stale": false, "error": "" }
  },
  "basket": [                               // 品种清单（来自 BASKET）
    { "id": "pork_lean", "name": "猪肉（瘦）", "group": "肉", "xfd": "白条猪", "spec": "瘦" }
  ],
  "xinfadi": {                              // 单品日均价，元/斤，保留 400 天
    "pork_lean": { "2026-07-23": 7.25, "2026-07-24": 7.15 }
  },
  "xinfadi_meta": {                         // 最近报价日的最低 / 最高价、产地
    "pork_lean": { "date": "2026-10-22", "low": 6.75, "high": 6.75, "place": "" }
  },
  "moa_index_today": [                      // 全国指数今日快照
    { "name": "农产品批发价格200指数", "date": "2026-10-21", "value": 112, "prev": 111.78 }
  ],
  "moa_index_hist": {                       // 指数按天累积，保留 400 天
    "农产品批发价格200指数": { "2026-10-20": 111.78, "2026-10-21": 112 }
  },
  "rank": [                                 // 今日全国涨跌榜（原始单位）
    { "name": "豆角", "price": 6.8679, "last": 6.7365, "chg": 1.95, "unit": "元/公斤", "date": "2026-10-22" }
  ],
  "rank_hist": {                            // 上榜品种按天累积，已折算为元/斤
    "豆角": { "2026-10-21": 3.368, "2026-10-22": 3.434 }
  },
  "cpi": {                                  // 按月份，最多 36 个月
    "2024-10": {
      "cpi":  { "mom": -0.3, "yoy": 0.3 },
      "food": { "mom": -1.2, "yoy": 2.9 },
      "url": "统计局公报地址"
    }
  }

```

`cpi` 每月可能含的品类 id：`cpi`、`food`、`core`、`grain`、`veg`、`pork`、`meat`、`beef`、`mutton`、`aquatic`、`egg`、`fruit`、`oil`（以当月公报表格实际有的行为准）。

本项目只有 `data.json` 一个数据文件，没有其他 json / ics / 快照文件；历史数据直接累积在 `data.json` 内（`xinfadi`、`moa_index_hist`、`rank_hist`、`cpi`）。

## 前端

**详情抽屉 + 列表页（kit 通用组件）**：电脑上从右侧滑出，手机上从底部升起。地址格式 `#/item/<类型>/<id>`、`#/list/<key>`，分享链接可直接打开对应详情；条目已下榜 / 过期 / 不在当前数据里时，弹出「这条内容已不在当前数据里」的提示，并提供回到首页按钮。

列表页是新开的一层：从右侧滑入盖在首页上，返回时滑走；首页一直在底下不动，滚动位置不变。在列表里点开的详情盖在这一层之上；直接打开列表链接时不播进场动画；安卓手机可从左边缘右滑返回（iOS 用系统自带手势）。

本项目的条目类型：

| 类型 | id | 内容 |
|------|----|------|
| `veg` | `BASKET` 里的品种 id（如 `#/item/veg/pork_lean`） | 新发地单品：最新价、较昨日 / 7 天 / 30 天涨跌、当日最低最高价、产地、走势图（`?r=30/90/365` 切 30 天 / 90 天 / 1 年）、同组品种 |
| `cpi` | CPI 品类 id（如 `#/item/cpi/pork`） | 近 24 个月同比、环比折线和逐月表，带统计局公报原文链接 |
| `rank` | 涨跌榜品种名（URL 编码） | 全国均价（元/斤）、较前一天涨跌、上榜日累积走势、同榜其它品种 |
| `index` | 指数名（URL 编码） | 指数今日值、前一天值、累积走势、其它指数 |

列表页 key：`movers`（`#/list/movers`，全部品种涨跌）。支持 `?g=肉|蛋|菜|果|鱼虾` 按分组筛选、`?sort=d7|-d7|d30|-d30|d1` 排序，每页 30 条，可「加载更多」。

**项目特有功能**：
- 四个视图：概览 / 今日菜价 / 全国行情 / CPI，当前视图存在 `localStorage`（前缀 `fp:`），不进地址栏
- 今日菜价表点一行展开走势图（30 天 / 90 天 / 1 年），悬停看每天价格；CPI 视图可在走势图和表格间切换
- 右栏：「常买的几样」（瘦猪肉、鸡蛋、西红柿、土豆、黄瓜、苹果）、数据来源状态（正常 / 旧数据 / 失败）和新发地最新报价日
- 搜索（`⌘K` / `Ctrl K`，`Esc` 清空），深浅色切换，涨红跌绿并带 ▲▼ 箭头
- 跨越手机 / 电脑宽度时重画图表（两种宽度的 SVG viewBox 不同）

## 本地运行

```
python3 scraper.py
python3 -m http.server
```

- 依赖：Python 3（GitHub Actions 用 3.12），只用标准库，无需 `pip install`
- 环境变量：无，不需要任何密钥
- 运行后在当前目录生成 / 更新 `data.json`；浏览器打开 `http://localhost:8000` 预览（直接双击 index.html 用 file:// 打开读不到 data.json）

## 自动更新机制

| 触发方式 | 时机 |
|---------|------|
| GitHub Actions 定时任务（cron `0 1 * * *`） | 每天 09:00 北京时间（新发地前一天的价格已发布） |
| push 到 main 分支 | 仅当改动了 `scraper.py` 或 `.github/workflows/scrape.yml` 时 |
| GitHub Actions 手动 dispatch | 按需触发 |

- 运行后只提交 `data.json`，提交信息为 `data: update <北京时间>`；`concurrency: scrape` 保证同一时间只跑一个任务
- **心跳**：`data.json` 里的 `updated` 每次运行都会变，所以每次都会产生提交，仓库保持活跃。GitHub 会在仓库 60 天无提交时自动停用定时任务，靠这个心跳避免被停用；如果仍被停用，到 Actions 页面重新启用即可
- 某个来源抓取失败不会中断整体运行，沿用旧数据，页面右栏标「旧数据」
