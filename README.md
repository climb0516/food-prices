# 🥬 菜价物价 · 猪肉 鸡蛋 蔬菜 CPI

> 每天看猪肉、鸡蛋、蔬菜、水果、鱼的批发价涨跌，全国批发价格指数，以及国家统计局每月的 CPI（猪肉、鲜菜、蛋类同比）

**🌐 在线访问：[https://climb0516.github.io/food-prices/](https://climb0516.github.io/food-prices/)**

---

## 功能

- **概览**：猪肉、鸡蛋、大白菜今日批发价，和 7 天前、30 天前比的涨跌，带 30 天走势线；最新 CPI 同比和「菜篮子」指数；这周涨得最多、跌得最多的品种；一句话看 CPI（猪肉、鸡蛋、鲜菜比去年贵了还是便宜了）
- **今日菜价**：32 个常见品种（肉、蛋、菜、果、鱼虾），元 / 斤，和昨天、7 天前、30 天前比；点一行展开走势图（30 天 / 90 天 / 1 年），悬停看每天价格
- **全国行情**：农业农村部农产品批发价格 200 指数、「菜篮子」指数，以及蔬菜、水果、畜产品、水产品、粮食、食用油分类指数；今日全国涨跌榜
- **CPI**：近 24 个月 CPI 总体、猪肉、鲜菜、蛋类同比走势（可切换表格）；当月各品类同比对比
- 搜索（`⌘K` / `Ctrl K`），深浅色切换，手机适配。涨红跌绿，并带 ▲▼ 箭头

## 数据来源

| 来源 | 内容 |
|---|---|
| 北京新发地批发市场价格接口 | 每日各品种的最低、最高、平均批发价；取「斤」报价的平均价，首次运行回补 90 天 |
| [农业农村部全国农产品批发市场价格信息系统](https://pfsc.agri.cn/) | 每日批发价格指数（接口只给当天和前一天，历史从上线起每天累积）、每日涨跌幅前 20 的品种 |
| [国家统计局](https://www.stats.gov.cn/sj/zxfb/) | 每月居民消费价格公报里的分项表：总体、食品、核心 CPI、猪肉、牛肉、羊肉、蛋类、鲜菜、鲜果、水产品、粮食、食用油的环比和同比；首次运行回补 24 个月 |

**说明**：
- 单品价格是**北京批发价**，一般比超市、菜市场零售价低三到五成，看涨跌趋势更有参考价值
- 品种清单在 `scraper.py` 开头的 `BASKET`：新发地品名 + 规格（如「白条猪 / 瘦」「草鱼 / 750g-1000g」），增删直接改
- 季节性品种（如脐橙）没有报价的日子会空着，页面上显示最后报价日

## 技术架构

```
GitHub Actions（每天北京时间 09:00 / 手动 / 修改爬虫后 push）
  ↓ python scraper.py（只用标准库，无需安装依赖）
  ↓ 新发地查最近 7 天全部报价（历史不足的品种回补 90 天）
  ↓ 农业农村部指数、涨跌榜；统计局 CPI 公报（只解析新出的月份）
  ↓ 与上一份 data.json 合并（单品价格、指数保留 400 天，CPI 保留 36 个月）→ 写入 data.json 并 commit
       ↓
GitHub Pages（index.html）
  ↓ 前端读取 data.json，走势图用内联 SVG 绘制
```

- 新发地偶尔返回 503（限流），爬虫会等几秒重试
- 某个来源本次抓取失败时沿用上一次的数据，右侧「数据来源」标注「旧数据」
- 每次运行都会产生提交，仓库保持活跃，定时任务不会因 60 天无活动被 GitHub 停用

本地预览：

```
python3 scraper.py
python3 -m http.server
```
